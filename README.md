# Rodney Degracia

I'm a senior iOS engineer. I also build Python and AI-assisted developer tools, and I write up how each one works.

Site and case studies: [rodneydegracia.com](https://rodneydegracia.com)

## Projects

- [LoreBuilder CLI](https://rodneydegracia.com/lorebuilder/): A persistent world you can talk to, built as a Python CLI with RAG, Chroma, and SQLite sessions.
- [Bugmiester](https://rodneydegracia.com/bugmiester/): A localhost trainer for spotting Swift bugs, built with Python, FastAPI, and free-text scoring.
- [Monitor](https://rodneydegracia.com/monitor/): A personal AI coding agent CLI, a Python REPL with tools and task planning.
- [ultra-trace](https://rodneydegracia.com/ultra-trace/): Deterministic Swift static analysis that keeps assist and gate as separate steps.
- [Desktopper](https://rodneydegracia.com/desktopper/): Turns an ordinary-language request into a local schema-driven app with Python, SQLite, and Safari.
- [Maximus](https://rodneydegracia.com/maximus/): An LLM harness for contest machine learning, with a person approving each training run.
- [Greenfield](https://rodneydegracia.com/greenfield/): A spec-first harness for building a new app one verified unit at a time.
- [super-duper](https://rodneydegracia.com/super-duper/): A planning and execution CLI that turns a goal into a hierarchical plan and validated workspace artifacts.
- [llm-platform](https://rodneydegracia.com/llm-platform/): An LLM tool-calling runtime with a plugin host that works across model providers.
- [World-Sim](https://rodneydegracia.com/world-sim/): A local narrative simulation with split storage, grounded play modes, and a companion World Builder.
